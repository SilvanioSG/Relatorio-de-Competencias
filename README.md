# Relatório de Competências e Trajetória de Capacitação

> Aplicação web para análise, visualização e documentação de uma trajetória de capacitação profissional.
> 
**Acesse o Relatório de Competências:** https://silvaniosg.github.io/Relatorio-de-Competencias/

**Autor:** Silvanio Gois  
**Versão:** 1.0  
**Publicação:** 25 de agosto de 2026  
**Finalidade:** Portfólio profissional, documentação de aprendizado e demonstração prática de competências.

---

## 1. Visão geral

Este projeto transforma o histórico de capacitação profissional em uma aplicação web orientada a dados.

A proposta é organizar os registros de cursos, consolidar indicadores, analisar a evolução da formação e apresentar os resultados de forma visual e estruturada.

O projeto utiliza a própria trajetória de aprendizado como objeto de análise. Dessa forma, o repositório não funciona apenas como um catálogo de certificados: ele também demonstra a capacidade de organizar dados, desenvolver indicadores, criar visualizações e transformar informação em uma aplicação web.

### Principais números

| Período analisado | Março de 2020 a agosto de 2026 |

## 2. Objetivos

O projeto tem como objetivos:

- documentar a trajetória de capacitação profissional;
- organizar e estruturar os registros de formação;
- consolidar indicadores quantitativos;
- analisar a evolução da capacitação ao longo do tempo;
- identificar áreas de concentração de estudos;
- transformar dados em visualizações de fácil interpretação;
- demonstrar competências em análise de dados e desenvolvimento web;
- criar uma evidência prática para portfólio profissional.

O projeto complementa o currículo tradicional ao apresentar uma aplicação concreta em vez de apenas listar cursos e competências.

---

## 3. Origem e tratamento dos dados

A base inicial foi organizada no **Google Sheets**, utilizado como camada de consolidação dos registros de capacitação.

Os dados contemplam informações como:

- cursos;
- instituições;
- períodos;
- áreas de competência;
- carga horária;
- classificações utilizadas na análise.

O fluxo geral do projeto é:

**Google Sheets → Organização → Classificação → Análise → Indicadores → Desenvolvimento → Visualização → Aplicação Web**

A planilha representa a etapa de preparação dos dados. A aplicação web representa a etapa de transformação desses dados em informação visual e utilizável.

---

## 4. Processo de desenvolvimento

### 4.1 Organização

Os registros foram reunidos em uma estrutura única para permitir uma visão consolidada do histórico.

### 4.2 Classificação

Os cursos foram classificados por áreas de competência, instituições, períodos e demais atributos relevantes.

### 4.3 Consolidação

Os registros foram utilizados para calcular indicadores de quantidade, carga horária, distribuição e evolução.

### 4.4 Análise

Os dados consolidados permitem observar padrões de concentração, evolução temporal e mudanças no direcionamento da capacitação.

### 4.5 Desenvolvimento

Os resultados foram transformados em uma aplicação web utilizando tecnologias front-end.

### 4.6 Visualização

Os indicadores são apresentados por meio de gráficos, tabelas e componentes visuais.

### 4.7 Publicação

A aplicação pode ser disponibilizada como uma página web estática por meio do GitHub Pages.

---

## 6. Evolução da capacitação

A análise temporal indica mudanças no direcionamento dos estudos.

- **2020–2021:** trajetória mais generalista, com presença de Desenvolvimento Pessoal, Gestão e primeiros estudos relacionados à Análise de Dados.
- **A partir de 2023:** maior presença de Orçamentação e Planejamento.
- **2024:** maior volume de cursos relacionado à Análise de Dados.
- **Período posterior:** maior concentração em conhecimentos aplicados a orçamento e planejamento de obras.

Essa evolução deve ser interpretada não apenas pela quantidade de cursos, mas também pela mudança de foco ao longo da trajetória.

## 12. Por que transformar o histórico de cursos em uma aplicação?

Um currículo tradicional informa cursos, experiências e competências. Este projeto acrescenta uma dimensão prática: demonstra como um conjunto de registros pode ser organizado, analisado e transformado em uma aplicação.

O histórico de capacitação passa, portanto, a funcionar como um conjunto de dados para um projeto aplicado.

O resultado reúne, em uma única solução:

- documentação da capacitação;
- análise de dados;
- desenvolvimento web;
- visualização de informações;
- documentação de aprendizado;
- portfólio profissional.

### Configuração

No repositório do GitHub:

```text
Settings
→ Pages
→ Build and deployment
→ Deploy from a branch
→ Branch: main
→ Folder: / (root)
→ Save
```

Após a configuração, o GitHub Pages realizará o deploy da aplicação.

## 17. Limitações e interpretação dos dados

Os indicadores apresentados representam os registros utilizados na construção do projeto e devem ser interpretados dentro do contexto da base analisada.

A quantidade de cursos ou horas de estudo não determina, isoladamente, o nível de domínio de uma competência. Os dados demonstram a trajetória de capacitação registrada, enquanto a aplicação demonstra a capacidade de organizar, analisar e comunicar essas informações.

O projeto também não substitui currículo, histórico profissional, experiência prática ou avaliação técnica.
